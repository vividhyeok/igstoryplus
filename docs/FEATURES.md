# 사용 범위와 동작

## 기본 흐름

사진·영상은 시스템 파일 선택기, 촬영은 시스템 카메라로 가져온다. 사진 한 장만으로 바로 저장/공유할 수 있다. Instagram 계정·서버·광고·원격 AI는 사용하지 않는다.

사진 배경과 추가 사진은 원본 URI를 유지하며 크롭만 저장한다. 자르기 화면은 드래그/핀치, 자유·1:1·4:5·9:16, 위치·확대·회전·반전을 제공한다. 사진 레이어·텍스트·PNG·음악 카드는 PhotoEditor 제스처로 이동·핀치·회전한다. 복제·삭제·순서 변경·문서 Undo/Redo·중앙 스냅/보조선을 제공한다.

## 표현

Simple, Grainy, Gritty, Lores, Handheld, Zoomblur, Flow Blur는 배경 사진/원본 영상에 적용한다. 강도는 낮게, 모션/Beat Glow는 OFF로 시작한다. 자동 블러 배경은 사진을 9:16 안에 맞추고 같은 사진에서 채운다. 배경 블러/밝기/색감과 효과 범위·루프 속도를 조절할 수 있다. 효과는 별도 고해상도 CPU 블러를 매 프레임 계산하지 않는다.

텍스트는 한국어/영어·정렬·색상·크기, 기본/세리프/모노 및 사용자 TTF/OTF를 지원한다. Soft Label, Offset Type, Whisper, Drift Type, Echo Type을 제공한다. Whisper는 가는 글꼴·자간·투명도를 조합한다. 모션 텍스트는 작은 위치 변화이며 큰 등장/반동 애니메이션은 없다.

PNG는 SAF 폴더에서만 가져온다. 앱 진입 시 재조회와 수동 새로고침, 폴더 변경, 즐겨찾기·최근, 투명 여백 보정, 약한 크기 모션을 제공한다. 샘플 이모지는 설치 앱에 없다. RecyclerView/Glide로 보이는 썸네일만 로딩·캐시한다. 공급자의 URI 권한이 만료되면 재선택한다.

## 로컬 음악

Android가 디코딩 가능한 MP3/M4A/WAV/FLAC 등. 메타데이터·내장 앨범 아트를 읽고 곡명/아티스트/앨범과 별도 아트를 수정·재사용한다. 작은 카드·아트·텍스트·숨김을 지원한다. 사진 음악은 기본15초, 5–15초를 1초 단위로 조절하며 마지막 값을 기억한다. 시작 위치를 바꾸고 선택 구간을 듣는다. 영상은 원본 길이를 최대60초까지 유지한다. 오디오 구간이 짧으면 출력 길이까지 반복한다.

Beat Glow는 기존 rhythm-mp3의 적응형 온셋 선택을 축소 적용한 에너지 반응이다. 정밀 BPM/스펙트럼 분류 전체를 포팅한 것은 아니다. 분석 결과는 URI·구간별 캐시하고 강도 변경 시 재분석하지 않는다. 낮은 진폭/완만한 감쇠/최소250ms 간격으로 밝기를 제한한다. 카드의 미세 모션은 느린 루프이며 정밀 비트 기반 Cover Pulse라고 광고하지 않는다.

## 미리보기·출력·공유

캔버스가 미리보기 화면이다. 재생 버튼은 저해상도 GPU·영상 디코더·음악 재생과 레이어 모션을 약30fps 시계로 구동하며 Exporter나 인코더를 호출하지 않는다. 영상 프레젠테이션 시점을 기준으로 음악의 큰 드리프트를 보정한다. 저장·공유를 누를 때만 고해상도 인코딩한다. 실제 하드웨어/디코더에 따라 프레임 지연과 미리보기·출력의 작은 차이는 있을 수 있다.

움직임 없는 사진은 JPEG92, 모션·음악·영상은 H.264/AAC MP4, 유효 표시 해상도1080×1920, 기본30fps, 요청 비트레이트6Mbps/160kbps. 60fps 같은 높은 프레임 영상은30fps로 낮추고, 24fps 등 낮은 원본은 원래 간격을 유지한다. 인코더가 회전 메타데이터를 쓰면 저장 픽셀은1920×1080이고 표시 방향이90도일 수 있다. 파일 검사는 회전까지 반영한다. 사진 모션 기본5초, 최대15초. 원본 영상 최대60초. 출력 진행/취소/실패 재시도와 갤러리 저장을 제공한다.

Instagram ADD_TO_STORY에 FileProvider Content URI, MIME, ClipData, 읽기 권한을 전달한다. 미설치/미지원/권한 오류는 일반 공유·갤러리 저장으로 전환한다. 실제 게시 성공이라고 표시하지 않는다. 공식 음악·멘션·위치·질문·투표·링크·공개 범위·게시 작업은 Instagram에서 진행한다.

초안은 하나를 자동 저장하며 원본 참조·크롭·레이어·폰트·음악 구간을 복원한다. 작성 중인 텍스트는 별도 복구 파일에 저장하여 앱 재생성 시 이어 쓸 수 있다. 취소하면 기존 텍스트를 그대로 유지하며 새 텍스트는 생성하지 않는다. 프리셋은 스타일/배경·모션·첫 텍스트의 표현/폰트/크기·음악 카드/모션·사진 영상 길이를 저장한다. 원본 삭제/권한 만료는 재선택으로 복구한다. 공유 실패 결과와 초안은 보존한다. 미리보기용 영상 파일은 만들지 않는다.

## 기기 확인 범위

자동 검증은 기능별 코드·시스템 API·실제 렌더링 파일을 다룬다. Samsung 카메라/문서 공급자, Galaxy S22의 열·메모리·인코더 성능, 실제 Instagram 버전의 전용 공유 수신·게시 후 화질은 실기기 확인이 필요하다. 성능 목표를 측정값으로 광고하지 않는다.
