igstoryplus v0.4.2 — 직접 만든 이모지를 텍스트 안에

예수님·교회 등 사용자가 만든 PNG 이모지를 문장 중간에 넣을 수 있습니다. 텍스트 편집 → 하단 '내 이모지' → 원하는 그림을 누르면 현재 커서에 삽입되고 선택 영역이 있으면 대체합니다. 별도 스티커 레이어를 만들지 않고 글자 한 칸처럼 커서 이동·삭제·선택·줄바꿈·크기 조절을 따릅니다.

기존 기본 개인 이모지 10종과 연결된 SAF 내 폴더의 PNG를 같은 입력창에서 선택합니다. 일반 Unicode 이모지도 기존 😀 버튼에서 사용할 수 있습니다. 원본 파일을 바꾸지 않고 이미지 참조를 텍스트 초안에 함께 저장합니다. 편집 재개·초안 복원·실행 취소/다시 실행과 JPEG/영상에 쓰이는 공통 텍스트 렌더링이 같은 이미지 글리프를 사용합니다. 외부 앱에서 사용할 수 있는 표준 Unicode 문자를 새로 만드는 기능은 아닙니다.

검증: API35 휴대폰 에뮬레이터에서 StoryUxTest 4개 통과. 실제 개인 예수님·교회 이미지 삽입, 커서 위치, 한 칸 삭제와 재삽입, 작성 중 화면 재생성 후 복원, 여러 줄 배치, 렌더링된 이미지의 컬러 픽셀과 실제 JPEG 출력 성공을 확인했습니다. 단위 테스트 34개 및 lint 통과. 새 이모지 테스트를 최종 변경본에서도 다시 실행했습니다. 전체 장시간 미디어/계측 테스트는 반복하지 않았고, 새 MP4 디코딩 및 Galaxy S22 실기기·실제 Instagram 공유는 미확인입니다. 배포 APK의 버전·기존 지속 키 서명·업로드 후 다운로드 일치를 검사합니다.

v0.4.1의 텍스트 스타일/배경, 사진을 가리지 않는 조절 패널, 정렬 자석/수평, 음악 카드 등 기존 기능을 유지합니다. 개별 사진 필터는 정적이고 Ambient/Aura는 사진 배경 전용입니다.
