직접 만든 이모지를 넣었을 때 글자 배경이 깨지던 부분을 수정했습니다. 여러 줄의 채움·반투명·라인 배경을 하나의 연결된 윤곽으로 그려, 반투명 겹침선과 내부 테두리를 제거했습니다. 이모지는 줄 높이 안에 들어가고, 타이핑 중 기존 이미지 span을 유지합니다. 예수님·교회 등 개인 이모지 원본과 기존 초안을 유지합니다.

플러스 효과: 글자·사진·스티커 윤곽에 하트 글리터/별빛을 붙이고 강도를 조절합니다. 음악 반응을 켜면 박자와 반짝임이 함께 반응하며 선택한 레이어의 미세 박동도 따로 켤 수 있습니다. 음악 없이도 부드럽게 반복합니다. 미리보기와 출력이 같은 효과 렌더러를 사용합니다.

Instagram에서 편집한 뒤 내려받은 MP4도 다시 가져와 '음악 → 원본 영상 소리로 반응'을 선택할 수 있습니다. 파일에 실제로 저장된 소리를 분석하며 음악 트랙을 중복 추가하지 않습니다. 저장 파일에 음악이 없다면 자동 복원하지 못하며 새 음악 파일을 추가할 수 있습니다. 자동/원본 영상/추가 음악 중 반응 기준을 선택합니다.

빛·색 반응 대상은 배경만/원본 화면 전체를 구분합니다. 사진의 '배경만'은 사진 뒤 여백이며 전체는 원본 사진·영상에도 적용됩니다. 별도 레이어의 효과는 선택해서 켭니다. 이미 영상에 합쳐진 글자·스티커는 분리되지 않으며 영상 프레임의 일부로 함께 반응합니다. 배경만은 전체 영상에는 적용되지 않습니다.

배치에는 가로/세로 중앙, 수평, 위치 잠금, 출력에 포함되지 않는 게시 UI 여백 안내를 추가했습니다. 안내선은 기기별 Instagram UI의 정확한 경계를 보장하는 규격이 아닌 배치 참고선입니다. 복제/삭제/사진 자르기/교체는 레이어 더보기에 모아 밀도를 낮췄습니다. 텍스트 완료 후에는 선택 상태를 유지해 바로 플러스/배치로 이어집니다.

SVG 아이콘 36개를 24단위 그리드·1.8 선 굵기·둥근 끝/모서리로 통일했습니다. 사진 스타일은 필름, 추가 효과는 플러스 반짝임으로 구분하고 정렬·잠금 등을 추가했습니다. SVG 원본은 vector-icons.zip 및 저장소 design/icons에 있습니다.
