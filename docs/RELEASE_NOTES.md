# igstoryplus v0.5.2 — 내 취향 스티커와 찾기 편한 선택창

차 한 잔, 펼친 책, 코딩 노트북, 헤드폰 투명 PNG 4종을 새로 생성해 기본 이모지를 33종으로 늘렸습니다. 음식·카페, 독서, 개발·작업, 일상·취미 분류와 한글/영문 검색어를 포함합니다. 기존 29종과 개인 PNG 폴더는 유지됩니다.

스티커 선택창에서 검색과 분류를 위에 고정하고 목록만 독립적으로 스크롤합니다. 선택한 탭·분류는 밝은 배경으로 표시됩니다. 검색 지우기, 직접 누르는 48dp 즐겨찾기 별 버튼, 빈 목록별 안내와 폴더 오류 복구 안내를 추가했습니다. 화면 너비에 따라 3~6열로 조정합니다.

최근 사용은 즐겨찾기 여부에 관계없이 실제 사용 순서를 유지합니다. 여러 단어를 입력하면 모든 단어에 맞는 스티커를 찾습니다. 문장 안 이모지 목록에도 분류·최근 사용·즐겨찾기를 추가하고, 스티커와 같은 최근 사용 기록을 공유합니다.

검증: 릴리스 빌드 전에 Android lint, 앱·편집 엔진 단위 테스트 및 별도 Validate Story Plus 실행을 요구합니다. 새 PNG의 투명 여백, 문장 삽입/직렬화, 선택창 검색·초기화·즐겨찾기·최근 사용을 포함합니다. 실제 실행 결과는 연결된 Actions 검증 기록에서 확인할 수 있습니다. Galaxy S22 실기기, 실제 Instagram 게시, 장시간 발열, 30/60초 전체 출력 반복은 이번 검증 범위에 포함하지 않습니다.
