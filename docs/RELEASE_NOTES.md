igstoryplus v0.4.1 — 텍스트 이모지와 스토리 편집 UX

😀😃😄😁 같은 Unicode 이모지를 문장 안의 커서 위치에 넣습니다. 선택한 글자를 이모지로 바꾸고, 한글과 컬러 이모지가 함께 저장·출력됩니다. 기존 개인 PNG는 별도의 '스티커'로 유지합니다.

텍스트 편집은 상단 정렬·배경·색상·완료, 하단 폰트 한 줄, 옆 크기 조절로 정리했습니다. 클래식/모던/굵게/타자기/네온/외곽선과 없음/채움/반투명/라인 배경을 추가했습니다. 배경은 줄 길이를 따라 그리며 채움 색에 맞춰 글자 대비를 조절합니다. 텍스트 한 번 탭으로 다시 편집하고, 기존 폰트·스타일·초안을 유지합니다.

사진 스타일과 음악 구간/카드 조절은 캔버스 아래 패널에서 합니다. 9:16 화면 전체가 보이도록 작업 화면이 줄어들며 패널이 사진 위를 덮지 않습니다. 사진 이동에 중심 자석·방향 잠금·수평 회전 자석을 추가하고, 사진 레이어와 배경에 '수평' 버튼을 제공합니다. 핀치 확대 중 실제 손가락 각도와 회전이 일치하도록 좌표 변환을 수정했습니다.

새 음악 기본 '스토리'는 흰 둥근 카드에 앨범 커버·곡명·아티스트를 표시합니다. 큰 커버/투명 스타일도 선택할 수 있고 기존 음악 카드는 유지합니다. Instagram의 글꼴이나 고유 에셋을 복제하지 않고 Android 기본 글꼴로 스타일을 구현했습니다.

검증: Android 15/API35, 1080×2340 에뮬레이터에서 신규 UI 테스트 3개, 기존 텍스트·배경·드래그 회귀 테스트 3개 통과. 단위 테스트 33개 및 lint 통과. Unicode 교체/커서/재생성/컬러 출력, 패널과 캔버스 비중첩, 실제 핀치 각도·배율·수평 복귀를 확인했습니다. 이전 v0.4.0 CI에서 실패했던 텍스트 재편집 테스트도 새 UI에 맞춘 조작으로 로컬 통과했습니다. 전체 25개 계측 및 장시간 미디어 검증은 이번에 다시 돌리지 않았습니다. 배포 작업은 release 빌드·패키지·지속 키 서명·업로드 후 다운로드 일치를 검사합니다.

Galaxy S22 실기기, 실제 Instagram 앱의 공유 수신·게시, 장시간 성능은 미확인입니다. 이모지 모양은 Android/키보드에 따라 달라집니다. 개별 사진 필터는 정적이며 Ambient/Aura는 사진 배경 전용입니다. 이전 기능과 기존 초안 형식은 유지합니다.
