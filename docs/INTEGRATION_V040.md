# igstoryplus v0.4 통합 결과

## A. 구현 범위

Kotlin, GLES2, Media3, PhotoEditor 구조를 유지했다. 개인 기본 이모지, 사진 10개 스타일, 음악 반응, 카드·텍스트, 영상 직접 제스처, 개별 사진 스타일과 레이어 모션, 이름 있는 초안과 프리셋 썸네일을 통합했다. Android 10+ / target SDK 35.

## B. 편집 UX

9:16 캔버스와 선택 레이어 도구를 유지한다. 사진·영상은 캔버스에서 이동/핀치/회전하며 원본 구도로 복귀할 수 있다. 실행 취소/다시 실행 가능 상태가 제스처 후 즉시 갱신된다. 텍스트는 실제 IME 입력을 사용하며 스타일 변경 시 setText로 조합·커서를 초기화하지 않는다. 기존 더블탭·IME 복원 검증은 유지한다.

## C. 개인 이모지

Desktop/emoji 원본 10개를 전부 검사하고 전부 포함했다. 손상·파일/픽셀 중복·제외 0개. 1254×1254 RGBA 원본은 보존하고 512×512 RGBA 복사본만 생성했다. 비율 유지, 알파 경계 기준 최대 448px 내용 영역, 중앙 배치. 배경 색 추정·제거는 하지 않았다.

교회·신앙 4, 여행·자연 2, 음식·카페 2, 독서 1, 패션·빈티지 1. 기본/내 폴더/최근/즐겨찾기, 검색·분류, Glide 지연 썸네일을 지원한다. 안정된 asset URI와 기존 SAF URI는 초안·Undo·내보내기에서 공통으로 읽는다. 원본/정규화본 해시는 emoji-audit.json에 기록했다.

## D. 사진 스타일

- Grainy: 휘도에 따른 미세 입자. Gritty: 그림자 입자와 국소 대비.
- Lores: 240×426 샘플링, 약한 색 어긋남·양자화 혼합. 큰 네모 타일을 줄임.
- Handheld: 주기적인 복합 흔들림. 강도 0의 고정 확대 제거.
- Zoomblur: 중심에서 가장자리로 방사형 샘플.
- Flow Blur: 독립된 곡선 방향 샘플. 기존 Zoomblur 분기 중복 제거.
- Shutter Drag: 한 방향 잔광. Sensor Raw: 어두운 영역의 센서 잡음. Frame Echo: 약한 이중 노출.

Simple 포함 10종. 풍경·바다·인물·야경·카페 실사진 각각에서 0/25/100%를 Android GPU로 렌더한다. 0% 동일성, Grainy/Gritty와 Zoomblur/Flow 차이, 6종 모션의 시간 변화·루프 접합을 자동 검사한다. 동적 입자는 두 고정 잡음장의 주기 보간으로 경계 튐을 줄였다. bf6f868 셰이더를 androidTest에 고정해 동일 사진의 이전/이후 비교도 생성한다. 테스트 사진 출처와 라이선스는 quality-fixtures.json 참고. Instagram 내부 알고리즘과 동일하다고 주장하지 않는다.

## E. 음악

50ms 단위 에너지, 180Hz/2400Hz 경계의 저·중·고 대역, 12개 Goertzel 프로브의 양의 스펙트럼 플럭스, 온셋, 빠른/느린 엔벨로프를 분석한다. 침묵 게이트와 95백분위 정규화, 파일 변경·구간·반복을 포함한 디스크 캐시를 사용한다. 악기 분리/인식은 하지 않는다.

빛 반응은 기존 가장자리 반응을 유지한다. Ambient Breathing은 사진 뒤 흐린 배경에만 미세 확대·연화·밝기, Album Aura는 커버 평균색을 배경에만 혼합한다. 원본 사진 중앙과 오버레이는 유지된다. Music Dot은 카드 모서리의 작은 원으로 반응한다. 영상에서는 빛 반응/Music Dot을 제공하며 사진용 배경 반응은 원본 영상에 적용하지 않는다. ON/OFF·강도·반응 종류를 음악 구간에서 바꾸며 재생을 유지한다.

프리뷰와 MP4는 같은 분석 배열과 보간을 사용한다. 실제 온셋과 GPU/MP4 밝기 차이는 beat-sync.json에 기록한다. 원본 영상·추가 음악은 독립 볼륨으로 믹스한다. 짧은 음악의 자동 반복은 하지 않는다.

## F. 카드·텍스트·확장 작업

Mini Credit, Cover Caption, Mono Tag, Progress Line 카드 4종을 추가했다. 기존 4개 표시 카드와 숨김을 유지한다. 긴 한글은 경계를 넘지 않게 말줄임하고 누락 아트는 음악 아이콘으로 처리한다. Progress Line의 선·진행점과 Music Dot은 실제 시간에 따라 이동하며 프리뷰 Drawable과 출력 Bitmap이 같은 함수를 사용한다.

Film Caption, Mono Stamp, Editorial Serif, Margin Note를 추가했다. 기존 6종과 개인 폰트를 유지한다. 960px 기준 글꼴·간격·크기·장식은 IME 입력과 최종 렌더에 공유한다. Margin Note는 선택 시 왼쪽 여백에 배치한다.

사진 레이어는 배경과 독립된 정적 필터를 갖는다. 레이어 모션 기본/숨쉬기/떠오르기와 강도는 시간축에서 공유된다. 여러 이름 있는 초안은 독립 JSON/썸네일, 열기/이름 변경/삭제를 제공하며 현재 자동 초안과 분리한다. 프리셋은 현재 사진에 스타일·텍스트·카드를 합성한 썸네일을 보여준다.

## G. 검증

로컬 API 35 에뮬레이터에서 개별 핵심 검사와 신규 품질 검사 6개를 통과했다. 전체 lint/단위/계측 검증과 CI 결과는 진행 기록 및 Release의 validation-report.json에 확정한다. 실패를 무시하거나 테스트를 비활성화하지 않는다.

계측은 실제 SAF 권한·기본 이모지·IME·재생 중 컨트롤·사진/영상 제스처·복원·JPEG·H.264/AAC 5/15/30/60초·오디오 믹스·GPU/MP4 비트·동적 진행점·레이어/초안을 검사한다. 5개 실사진×10종×3강도 비교는 style-comparisons.zip으로 제공한다. 실제 UI 캡처는 ux-screenshots.zip.

ActivityScenario.onActivity가 연속 재생 중 waitForIdleSync에서 멈추는 것을 로컬 JDB 스택으로 확인했다. 현재 활성 Activity의 메인 스레드에 상태 점검을 직접 전달하도록 테스트 접근 방식을 수정했고 동일한 UI 조작과 검증 조건을 유지했다.

## H. 배포

정식 목표 버전 v0.4.0. main과 workflow_dispatch release_version으로 전체 검증을 완료한 뒤 태그·Release를 만든다. 지속 서명키를 재사용하고 universal APK 하나만 제공한다. 서명·패키지·versionName/code·SHA256 및 다운로드한 APK와 빌드 산출물 일치를 확인한다. 확정 commit/Actions/다운로드/해시는 완료 보고에서 기록한다.

## I. 남은 제약

Galaxy S22 실기기, Samsung 카메라·문서 공급자, Instagram 앱의 실제 공유 수신·게시, 장시간 발열·배터리는 미검증이다. 에뮬레이터 검사로 대체했다고 주장하지 않는다. 개별 사진 스타일 자체의 GPU 모션은 정적이고 레이어 변환 모션을 사용한다. Ambient/Aura는 사진 배경 전용이다. 악기 인식, 클라우드 초안, Instagram 공식 음악 연결은 제공하지 않는다. 공유 Intent 검증은 게시 성공을 의미하지 않는다.
