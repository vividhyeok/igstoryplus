# v0.4.1 Story editing UX

Inline Unicode emoji replaces the previous ambiguity between text emoji and PNG stickers. Text uses native editable Unicode and per-line text backgrounds shared by canvas input and exported Artwork bitmaps. Existing saved layers default to legacy decoration; new layers default to Classic/no background. Existing asset library is labeled Stickers.

EditorDock reserves vertical space below the complete 9:16 canvas for photo style and music card/range controls. Text uses compact top controls, one font strip and a side size slider. Native keyboard can be exchanged for a two-row emoji tray. Existing advanced fonts remain available.

Alignment uses raw gesture intent, magnetic hysteresis, center guides, rotation leveling and an explicit level action. Layer pinch measures initial/current spans in screen space to prevent rotated/scaled view coordinates from distorting physical finger rotation. A completed short text tap reopens editing.

New Story/Cover/Transparent music styles keep song/artist visible. Existing card IDs remain supported. Persistent signing identity and package ID remain unchanged.

Local validation on API35 phone geometry 1080x2340: 33 unit tests, lint, three StoryUxTest cases and three EditorUiTest regression cases passed. The latter preserve composition/restore/double-tap assertions; interactions use the new control labels. New UI tests exercise emoji replacement/caret, colored rendered glyph output, restored single-tap editing, nonoverlap of canvas/panels, physical pinch angle/scale and level action. Screenshots are real Android UI captures, not design mockups. Full legacy 25-case/media suite was not rerun; Galaxy S22 and actual Instagram sharing remain unverified.

Design reference: Meta Engineering, Building text animations for Instagram Stories, https://engineering.fb.com/2022/07/18/developer-tools/building-text-animations-for-instagram-stories/ . Native Android fonts are used, not proprietary Instagram assets. Static photo filters and photo-only Ambient/Aura limitations remain.
